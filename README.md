# padezhi_auto_podpiska

Telegram-бот для мониторинга каналов. Он ищет ключевые слова и фразы в новых постах, учитывает леммы через `pymorphy2`, подсвечивает совпадения и отправляет найденные посты в целевой канал. Фото, видео и документы из найденных постов тоже отправляются вместе с подписью.

## Возможности

- Мониторинг списка каналов из SQLite-базы `padezhi_auto_podpiska.sqlite3`.
- Первичная миграция ключей и каналов из `keywords.json` и `channels.json` при первом запуске.
- Поиск однословных ключей по леммам: например, ключ `Астрахань` найдёт падежные формы.
- Поиск фраз как точных подстрок.
- Отправка найденного текста, фото, видео, документов и альбомов в целевой канал.
- Админ-панель прямо в Telegram-боте через `/menu`.
- Добавление, удаление, изменение, поиск и просмотр ключевых слов без правки файлов вручную.
- Добавление, удаление, поиск и изменение меток Telegram-каналов без правки `channels.json`.
- Сохранение ключей, каналов и состояния в SQLite, чтобы меньше зависеть от ручной правки JSON.
- Лог ошибок в `errors.log` и просмотр последних ошибок через `/errors`.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

1. Скопируйте `config_telegram.example.json` в `config_telegram.json`.
2. Заполните `api_id`, `api_hash`, `phone_number`, `bot_token`, `channel_chat_id`.
3. В `admin_chat_ids` укажите Telegram ID пользователей или чатов, которым разрешено управлять ключами.
4. Заполните `channels.json` каналами для мониторинга.
5. Заполните `keywords.json` стартовыми ключами.

`config_telegram.json` добавлен в `.gitignore`, чтобы токены и телефон не попадали в GitHub.

## Запуск

```bash
python padezhi_auto_podpiska.py
```

При первом запуске Telethon попросит код из Telegram/SMS. Если включена двухэтапная аутентификация, скрипт также попросит пароль 2FA.

## Управление в боте

Откройте чат с ботом от имени администратора и отправьте:

```text
/menu
```

Доступные команды:

```text
/add ключевое слово
/del ключевое слово
/rename старое => новое
/search часть_слова
/list
/stats
/reload
/ch_add @username | метка
/ch_add https://t.me/+invite_hash | метка
/ch_add -1001234567890 | метка
/ch_del ссылка_или_id
/ch_label ссылка_или_id => новая метка
/ch_check ссылка_или_id
/ch_search часть_ссылки_или_метки
/ch_list
/ch_reload
/errors
```

Кнопки в меню делают то же самое: можно управлять ключами, каналами, смотреть списки, проверять доступность канала, смотреть ошибки и перезагружать данные из SQLite.

### Что указывать для каналов

Для открытых каналов удобнее всего указывать `@username` или обычную ссылку:

```text
/ch_add @rian_ru | РИА
/ch_add https://t.me/rian_ru | РИА
```

Для закрытых каналов есть два рабочих варианта:

```text
/ch_add https://t.me/+invite_hash | Закрытый канал
/ch_add -1001234567890 | Закрытый канал
```

Invite-ссылка лучше, если аккаунт Telethon ещё не подписан на канал: бот попробует вступить по ссылке. Числовой ID вида `-100...` лучше использовать, когда аккаунт уже подписан на закрытый канал и этот канал виден в сессии Telegram.

Важно: мониторинг читает каналы через пользовательский аккаунт Telethon, а не через Bot API. Поэтому для закрытого канала именно этот аккаунт должен быть участником канала.

Проверить доступность можно так:

```text
/ch_check @rian_ru
/ch_check -1001234567890
```

Бот попробует получить канал через Telethon и прочитать последний пост. Если это получилось, канал доступен для мониторинга.

## SQLite и старые JSON

`keywords.json` и `channels.json` теперь используются как стартовые файлы для первой миграции. При первом запуске бот создаёт `padezhi_auto_podpiska.sqlite3` и переносит туда ключи, каналы и состояние обработки.

После миграции управление идёт через базу: изменения из бота сохраняются в SQLite. Если нужно начать с чистой базы, остановите бота, удалите `padezhi_auto_podpiska.sqlite3` и запустите снова.

`padezhi_auto_podpiska.sqlite3`, `errors.log`, `session_name.session` и `config_telegram.json` добавлены в `.gitignore`.

## Формат channels.json

```json
[
  {
    "link": "https://t.me/example_channel",
    "name": "Название канала",
    "custom_text": "Метка"
  },
  {
    "id": -1001234567890,
    "custom_text": "Закрытый канал"
  }
]
```

`custom_text` необязателен. Если он указан, бот добавит эту метку в сообщение о найденном посте.

## Формат keywords.json

```json
[
  "Астрахань",
  "Ахтубинский район",
  "важная фраза"
]
```

Однословные ключи индексируются по леммам. Фразы ищутся как фразы в нижнем регистре.
